# sirosen's jigs

This is a repository of free software, for anyone who wants to use it.

There are no quality guarantees. Some things are demos, some are more robust.

## Why "jigs"?

A "jig" in many crafts (for example, woodworking or blacksmithing) is an
assistive device for specialized tasks.
Unlike multitaskers like a rasp, saw, or screwdriver, jigs are generally
unitaskers, serving exactly one purpose.

Although some jigs are available for purchase, like mass-market woodworking
tools, many jigs are made in the shop to be bespoke and fit to the exact needs
of the craftsperson.

Jigs are also a kind of dance!
Hopefully, if you borrow or copy these tools, you'll be so happy with the
experience that you'll want to get up and dance. :)
